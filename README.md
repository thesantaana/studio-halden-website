# MĒTIS

Bilingual static portfolio for MĒTIS, an independent design studio working across identity, digital and visual design.

## Routes

- `/zh/` Chinese
- `/en/` English
- `/` redirects to `/zh/`

## Development

```bash
npm install
npm run dev
```

## Static build

```bash
npm run build
```

The exported site is written to `out/`.

## Content and assets

- Localized copy lives in `contents/` and `dictionaries/`.
- Studio imagery lives in `public/assets/metis/`.
